## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Roadmap experiment: E08; risks R5 and R9; requirements REM-1 through REM-5 and EXEC-4.
Outcome: find the smallest provider-neutral worker protocol that survives an in-process fake, SSH-backed Linux worker, and a macOS adapter stub shaped by E06 inventory.
Scope: capability/profile advertisement, non-blocking reservation, attestation, sandbox/session creation, CAS materialization, command/log/cancel/exit, output publication, bounded cleanup, reconnect, and orphan query.
Stable assumptions: no provider-specific universal option map; transport choice follows state-machine semantics.
Parallelism: begins after E06 establishes an initial macOS shape; may finish shortly after Gate 1 if it does not affect the first local slice. Own experiments/e08-worker-protocol only.
Test or fault scenario: ready cache hit before reservation, profile mismatch, transfer corruption, disconnect/reconnect, worker loss, cancellation, output publication failure, cleanup timeout, and orphan reconciliation.
Observability: protocol transitions, reservation/lease identity, attestation, transfer digests, logs/cursors, cancellation, cleanup, and reconnect state.
Rollback or removal: worker processes and SSH resources are experimental and cleaned within a declared bound.
Versioned formats: state-machine and wire envelopes are explicitly experimental; transport is not frozen.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 One typed core protocol drives an in-process fake and SSH-backed Linux worker, with a macOS stub reflecting E06’s initial shape
- [ ] #2 Reservation is non-blocking, profile attestation precedes execution, and cache hits require no worker wake or acquisition
- [ ] #3 CAS materialization, execution/logging, cancellation, output publication, bounded cleanup, reconnect, and orphan query have success and failure tests
- [ ] #4 The decision chooses one typed core, separated worker/sandbox/session protocols, or state-machine-first transport deferral without provider option leakage

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Freeze a contract-only Phase A under experiments/e08-worker-protocol before writing any protocol implementation. Bind by SHA-256 the complete W2 v1 graph and golden scenarios, the accepted integrity-fault fixture, the E04 cache/profile evidence and selected limitations, and the accepted E06 contract, profile identity, lifecycle shape, candidate matrix, and infrastructure blocker. Record the canonical EXEC-1..5, REP-1, REP-3..6, AGENT-3, AGENT-5, DUR-1, and DUR-3 mapping; preserve REM-1..5 only as stale ticket provenance. Declare the experiment and every state or wire envelope experimental, forbid production imports and provider-specific option bags, and expose a dependency-free Phase A verifier plus mutation tests.

2. Freeze the semantic state machine before implementation in machine-readable protocol/state-transition artifacts. Keep controller node state separate from capacity and resource lifecycles: ready -> cache_lookup -> cache_hit terminal, or cache_miss -> reservation_requested -> reserved -> worker_acquired -> attested -> sandbox_created -> inputs_materialized -> executing -> publishing -> succeeded; cancellation/failure may enter cancelling, reconnecting, lost, or orphaned before bounded cleanup and released. Define independent reservation/lease ownership, reusable worker identity, disposable sandbox identity, and optional namespace-owned session identity. Make every transition idempotent by operation ID, revision, and expected prior state; persist reason codes, monotonic event sequence, attempt, profile/transfer digests, cleanup deadline, and reconnect token before acknowledging transitions that can affect retry or ownership. Terminal node success remains distinct from cleanup_warning plus an orphan record.

3. Freeze the smallest typed semantic surface and experimental envelopes. Model capability/profile advertisement from cached provider snapshots; non-blocking TryReserve returning granted, queued, mismatch, or unavailable without provisioning; worker acquisition and exact-profile attestation; sandbox create/materialize; separate session acquire/reset/release for the E06 macOS shape; CAS Has/Get/Put operations with digest, size, media type, and resumable chunk identity; Exec, ordered Logs(cursor), Cancel, Wait/Exit; atomic Publish; Cleanup; Reconnect/Heartbeat; and QueryOrphans. Separate typed core commands/events/errors from transports. Provider extensions are discriminated, versioned capability values owned by an adapter, never map[string]any or project-visible universal options. Secret bytes, ambient SSH config, credentials, host paths, and provider instance options never enter plans, cache keys, durable events, or logs.

4. Freeze numeric thresholds and sample rules before Phase B. Run every correctness/fault case at least five times per adapter shape, retaining failed attempts. For 30 ready-result-hit samples, require p95 below 300 ms and exactly zero reservation, worker-wake/acquire, attestation, sandbox/session, execution, publication, and cleanup events. For 30 warm SSH/Linux cache-miss samples, measure cache miss through sandbox ready and require p95 below 2 seconds excluding declared queue time. Require TryReserve to return a typed immediate disposition within 100 ms while acquisition is deliberately delayed, proving no scheduler-thread provisioning. Require cancellation acknowledgement within 1 second; require execution/process termination, reservation release, and experiment-owned sandbox/session cleanup within 30 seconds or an exact durable orphan. Require log replay after reconnect to be gap-free, duplicate-free by sequence identity, and byte-equivalent from the last acknowledged cursor; require zero stale-success, corrupt-input use, profile rewrite, double publication, cross-attempt output, leaked reservation, unrecorded orphan, or cleanup of unowned resources. Run sample sets serially in a frozen order, distinguish queueing from service time, bind T1 benchmark-v2 records where timing applies, and forbid post-result threshold relaxation.

5. Freeze a fault matrix that maps every injected boundary to expected state, observable events, retry rule, ownership outcome, and raw trace path. Cover ready cache hit before any reservation; capability/profile mismatch before and during attestation; provider unavailable before acquisition; CAS missing blob, corrupted chunk, digest mismatch, partial materialization, and manifest tamper before use; disconnect before exec acknowledgement, during execution/log streaming, during publication, and during cleanup; permanent worker loss; cancel before placement and while running; non-zero exit versus infrastructure loss; duplicate/reordered command delivery; stale reconnect token; output collection failure, digest failure, and atomic publication failure; cleanup timeout; caller loss/lease expiry; orphan query/reconcile; and resume on a second compatible worker without rerunning or republishing the successful W2 build. Each injected case must have a stable typed error distinct from command failure.

6. Add a first mandatory review boundary after Phase A only. The proposed Phase A files are README.md, Taskfile.yml, contract.json, state-machine.json, envelopes.schema.json, thresholds.json, fault-matrix.json, decision-matrix.json, fixture-bindings.json, frozen-artifacts.json, protocol.sha256, scripts/verify_contract.py, and contract mutation tests, all under the claimed experiment subtree. 7. Implement the approved Phase B as disposable experiment-local Go code with no new production module or public package. Drive all three adapter shapes through the same controller/state-machine harness and typed semantic commands: a deterministic in-process worker with controllable clock/faults; an SSH-backed Linux adapter whose transport is a replaceable newline-framed request/event stream over one separately approved SSH invocation; and a macOS adapter stub that implements the E06 worker/sandbox/session boundaries and profile fields without simctl, Xcode, VM, filesystem, or host lifecycle mutations. Keep transport framing, reconnect token encoding, and wire version explicitly experimental; do not claim gRPC, Connect, HTTP, or SSH as a stabilized transport.

8. Make cache and attestation ordering executable and auditable. Resolve the immutable profile digest and complete W2 result key before placement, perform and verify the ready-result lookup first, and return typed artifact handles immediately on a hit. On a miss only, obtain a reservation, acquire/wake a worker, attest every planned profile field, and reject or quarantine mismatch before sandbox/session creation. A mismatch cannot mutate the planned profile or convert a planned hit into a miss. Treat result cache, mutable tool cache, and warm worker/provider state as different types and event namespaces.

9. Exercise CAS, execution, logs, cancel, publication, and cleanup end to end. Materialize only digest-verified immutable source and dependency manifests into an attempt-owned sandbox; verify every received chunk and final object before use. Execute the W2 build/test-shaped command through a bounded child-process runner, stream ordered structured stdout/stderr chunks with resumable cursors, make cancel idempotent, distinguish exit status from transport loss, collect only declared output paths with symlink/path confinement, and publish manifests atomically with compare-and-swap so partial or losing attempts never become visible. Run cleanup on a cancellation-detached deadline context, release reservation/session exactly once, and record cleanup_warning plus exact orphan identity when the 30-second bound cannot be met.

10. Exercise reconnect, loss, resume, and orphan reconciliation against the frozen W2 expectations.
