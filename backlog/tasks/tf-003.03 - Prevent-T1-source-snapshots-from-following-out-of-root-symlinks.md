## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Roadmap tranche: Risk Lab prerequisite; input E04; risks R4 and R5; requirements SRC-1 and REP-1.
Outcome: the integrity fixture never incorporates bytes reached through a symlink outside the declared source root.
Review evidence: a temporary probe created root/escape as a symlink to an external file; Snapshot.Take followed it through os.ReadFile and included its digest as escape.
Stable assumptions: this remains a fixture-level source identity demonstration, not the production snapshot/materialization design.
Parallelism: independent hardening task. Own fixtures/integrity-faults snapshot behavior, tests, and documentation only.
Test or fault scenario: external-file and external-directory symlinks, safe in-root symlinks under the chosen explicit policy, and concurrent mutation limitations.
Observability: rejection names the offending relative path and reason without reading or exposing external content.
Rollback or removal: keep the exploit probe as a regression test even if E04 selects a different snapshot mechanism.
Versioned formats: bump the fixture version if snapshot identity semantics change.

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Define the fixture-only symlink policy in snapshot.go: require the supplied root itself to be a real directory; reject every descendant symbolic link regardless of whether it targets an in-root file/directory, an out-of-root file/directory, or a missing target; return a stable error that names only the normalized relative link path and a non-secret reason. Keep this explicitly experimental and avoid assigning production Source/CAS semantics.
2. Refactor Take to open a confined os.Root, walk its rooted fs.FS, identify symlinks without resolving or reading their targets, and read ordinary files through the rooted API. Preserve sorted path:digest identity for ordinary files. Use rooted reads as the fail-closed backstop if concurrent mutation replaces a checked entry with an out-of-root symlink; do not claim a coherent atomic snapshot under concurrent mutation.
3. Extend snapshot_test.go with table-driven regressions for out-of-root file and directory links, dangling links, and in-root file and directory links under the reject-all policy. Assert errors.Is against the symlink error, the diagnostic contains the offending relative path/reason, no external secret bytes appear, no partial Snapshot is returned, and the external-file exploit cannot become a successful hash. Retain and strengthen ordinary-file determinism/source-mutation coverage as needed.
4. Update README.md to bump the experimental fixture version because snapshot semantics change, document the reject-all policy and its rationale, record the external-symlink regression evidence, and distinguish rooted escape prevention from remaining concurrent-mutation/materialization limitations. Do not change the store manifest schema or store behavior.
5. Format and verify with the fixture gate, focused/race tests, git diff --check, and repository-root mise exec -- task check. Record exact commands and results in implementation notes, then stop before checking acceptance criteria, adding the final summary, marking Done, or committing so the user can review the summary and diff.

Planning research (2026-09-03):
- The original Take used filepath.WalkDir plus os.ReadFile. WalkDir exposed symlink entries without following directory links, but os.ReadFile followed file links, so behavior was target-kind-dependent and external file bytes could be hashed.
- Chosen policy: reject the supplied root when it is a symlink and reject every descendant symlink uniformly before intentional content reads, including in-root file/directory links, out-of-root file/directory links, and dangling links. This avoids defining link identity/materialization semantics before E04.
- Go 1.25 os.Root confinement provides a fail-closed read path if a checked entry is changed to an external symlink. Concurrent source mutation can still make this toy snapshot inconsistent or substitute an in-root target and remains outside the fixture guarantee.
- backlog, mise, task, go, gofmt, git, and rg are installed. The pinned toolchain is go1.25.12 darwin/arm64 and exposes os.OpenRoot/os.Root. Direct baseline task check and go test -race ./... passed before implementation.

Implementation completed for review (2026-09-03):
- Added ErrSnapshotSymlink and the uniform reject-all policy for the supplied root plus in-root, out-of-root, and dangling descendant symlinks.
- Snapshot traversal and reads now use os.OpenRoot/os.Root; the opened handle is compared with the initially inspected root before walking. Rejections return a zero Snapshot and name only the relative path and policy reason.
- Added regressions for external file/directory links, dangling links, in-root file/directory links, root symlinks, diagnostic non-disclosure, and non-vacuous ordinary-file determinism.
