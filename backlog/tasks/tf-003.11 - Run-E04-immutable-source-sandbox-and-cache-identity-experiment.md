## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Roadmap experiment: E04; risks R4, R5, R9; requirements SRC-1 through SRC-5, EXEC-1 through EXEC-4, CACHE-1 through CACHE-6.
Outcome: determine whether immutable source, disposable local workspaces, declared profiles, and cache identity before provisioning can meet isolation and local-latency requirements.
Approaches: Merkle/CAS source plus copy-on-write workspace; Linux namespace/overlay; macOS APFS clone/sandbox controls; pooled container or microVM fallback.
Stable assumptions: result cache, tool cache, and warm worker state are distinct; attained reproducibility is stated explicitly.
Parallelism: first Risk Lab wave independent of E01. Own experiments/e04-source-sandbox-cache only.
Test or fault scenario: post-creation source mutation, concurrent W1 outputs, undeclared paths/env, complete identity inputs, ready cache hit, mismatched profile attestation, and cache-state separation.
Observability: source/definition/profile/policy/dependency digests, reservation count before and after lookup, sandbox latency, file-access denials, and attestation mismatch.
Rollback or removal: all mechanisms remain experiment-local; preserve failures and remove privileged resources after bounded cleanup.
Versioned formats: source manifest, profile, and cache evidence formats are experimental.
