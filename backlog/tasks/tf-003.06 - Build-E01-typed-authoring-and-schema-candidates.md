## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Roadmap experiment: E01; risks R1, R2, R10; requirements TYPE-1 through TYPE-6 and API-1.
Outcome: disposable, directly comparable authoring candidates demonstrate whether a concise typed project API can emit complete agent-discoverable schema without privileged operation evaluation.
Competing options: generic typed values with explicit registration; code generation from Go declarations; reflection-heavy registration; and a minimal TypeScript comparison emitting the same provisional schema.
Stable assumptions: T1 fixture identities and harness outputs are experimental; execution may be fake; no candidate becomes a production SDK or root module.
Parallelism: first Risk Lab implementation wave after conformance/root-gate hardening. Own experiments/e01-authoring-schema only.
Test or fault scenario: W1, W2 build/artifact half, W3 public surface, compile-time incompatible value misuse, invalid arguments, and schema discovery without invoking operation bodies.
Observability: record authored lines, visible concepts, annotations/reflection/generated code, build/discovery latency, and diagnostics per candidate.
Rollback or removal: retain candidates as evidence until the E01 decision; no production consumers.
Versioned formats: candidate schema envelopes and generators declare experimental versions.

Predeclared thresholds and protocol to encode in Phase A

5. Apply hard comparability gates to every viable candidate: emit deterministic W1, W2, and W3 schema documents with zero T1 conformance violations or diffs; emit the same synthetic effect probe; author the exact W1 logical composition with typed fake handles/nodes and emit a candidate-local normalized trace matching the Phase A oracle; produce byte-identical repeated output across 10 fresh processes; never read a golden as generation input; and expose one candidate-local verification command. A schema-only descriptor plus a panic sentinel cannot satisfy the W1 gate. Run candidate generation from its standalone subtree and compare outputs only after generation.
6. Apply safety and typing gates equally to A, B, C, and D: discovery and argument validation must not invoke operation bodies, proved by panic/file-write sentinels across 10 fresh processes; every candidate must type-check positive controls and fail semantic type checking for both incompatible Artifact[T] and incompatible Endpoint[T] composition; and every candidate must reject unknown arguments, wrong scalar types, invalid enum members, and a missing required synthetic-effect argument with stable operation/argument/expected/actual diagnostics. Go candidates use the pinned Go compiler. TypeScript D uses a candidate-local pinned semantic checker; Bun transpilation alone is not accepted, and unavailable reproducible installation is recorded as infeasibility.
7. Predeclare the E01 decision measures for TF-003.07. Warm W1 discovery uses the T1 benchmark v2 harness with 30 samples, a prewarmed executable/runtime before every sample, explicit cache dimensions, and an unchanged p95 threshold below 150 ms. Cold and warm driver build/discovery use 15 samples each and are recorded without inventing a new pass budget. Ergonomics use mechanically counted non-comment, non-blank user-authored LOC and a frozen vocabulary of author-visible concepts; the headline count must cover every author-maintained line needed for the complete W1 logical shape, including source acquisition, format/test/lint children, typed dependency flow, aggregation, and outputs. A non-reflection Go candidate must use at least 25% fewer user-authored W1 LOC and at least 30% fewer low-level concepts than the Phase A control. Record annotations/directives/tags, reflection sites, generator LOC, generated LOC, and duplicated metadata separately rather than hiding them in the headline count. No candidate may satisfy the threshold by embedding a hand-written schema document or excluding its authored fake composition.
8. Predeclare two blinded agent trials for TF-003.07 against a candidate-neutral sealed bundle containing emitted schema and invocation help but no implementation source. Both independent attempts must discover the requested W3 operation, repair invalid W1 arguments, and invoke the fake operation interface without source reads; preserve prompts, outputs, access controls, and failures. If the outputs are canonically identical, the trials test the shared schema once rather than pretending identical documents are independent UX variants.
9. Encode branch rules without relaxing a missed threshold: continue only if A or B passes every hard gate plus the ergonomic and warm-discovery thresholds; A wins on explicit registration evidence, B wins only if generation burden and stale-output diagnostics remain acceptable; if only reflection-heavy C works, stop and redesign; if Go candidates fail but the shared schema and D succeed, hand TF-003.07 the bounded TypeScript-pivot branch; if typed authoring shows no material gain over the control, narrow or stop.

Retain Phase B smoke evidence under the experiment: emitted schema documents, conformance and compile/type-fail logs, body-sentinel results, W1 logical traces, exact commands, tool versions, and candidate limitations. Provide measurement commands and manifests for TF-003.07, but leave comparative benchmark execution, blinded agent attempts, scoring, and the E01 branch decision to TF-003.07.
